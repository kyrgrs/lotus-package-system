# Lotus Package System

## 📋 Requirements
- [qb-core](https://github.com/qbcore-framework/qb-core) (v2.0.0 or higher)
- [ox_inventory](https://github.com/overextended/ox_inventory) (v3.0.0 or higher)

## 🌟 Features
- License-based authorization
- Customizable packages
- OX Inventory integration
- Multi-currency support (cash, bank, crypto)

## 🛠️ Installation
1. Place the `lotus-package-system` folder in your `resources` directory
2. Add `ensure lotus-package-system `to your server.cfg` file
3. Configure the `config.lua` file according to your needs
4. Restart the server

## ⌨️ Commands
- `/givepackage [packageID] [playerID]` - Distribute specified package to target player
